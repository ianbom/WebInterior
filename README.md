# Lifetime Design — website recreation

Responsive Next.js App Router frontend adapted to Lifetime Design's verified company information and official-site photographs, using M Design Group as a visual reference.

## Run locally

```bash
npm install
npm run dev
```

Routes: `/`, `/our-expertise`, `/about-us`, `/awards-articles`, `/contact`, and `/articles/[slug]`.

See `docs/reference-analysis.md`, `docs/asset-sources.md`, and `docs/implementation-notes.md` for audit findings, asset provenance, validation, and known limitations. The public website hosts its own copyrights; confirm permission for production redistribution of photography before launch.
